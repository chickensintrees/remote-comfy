# decisions/

One file per decision that had a real alternative: `YYYY-MM-DD-slug.md`.

Each note answers: **context** (what forced the choice), **decision**, **what was tried
or rejected**, and **what would change it**. Notes record what was true when written.
If the code now contradicts a note, that is a finding: fix one or the other.

Rules that can be asserted belong in `tests/test_runpod_ops.py`, not here. A note
carries only what cannot be made executable.
