# CI runs on ubuntu-24.04, not ubuntu-latest

**Context.** On 2026-11-14 the test job for Python 3.9 failed during setup, before any test
ran: `The version '3.9' with architecture 'x64' was not found for Ubuntu 26.04`.
`ubuntu-latest` had moved to 26.04, which has no Python 3.9 build. The 3.12 job passed.
The last green run before that (2026-10-23) was on 24.04.

**Decision.** Pin `runs-on: ubuntu-24.04` and keep 3.9 in the matrix, because the README
and the project page promise Python 3.9 or newer, and the pod's bare Python can be old.

**Alternative.** Drop 3.9 from the matrix and raise the stated minimum to 3.10.

**What would change it.** GitHub retiring the ubuntu-24.04 image, or a decision to stop
supporting 3.9. Either way, update the README's Requirements and the page's spec line
in the same change.
